# Footer

## Component

`src/sections/Footer.tsx`

## Purpose

The footer gives a premium close to the page, repeats the private briefing CTA, and provides navigation/contact details.

## Content

- CTA panel
- Brand lockup and tagline
- Footer navigation
- Private briefing contact
- Copyright line
- Back-to-top control

## Data Source

Brand contact details come from `src/data/site.ts`.

## Handoff Checks

- Confirm email and phone links use the final approved contact details.
- Confirm footer links use the `/cooperative/` base path correctly after deployment.
